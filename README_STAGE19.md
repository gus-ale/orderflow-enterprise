# Stage 19 — Portfolio, Demo y Defensa Técnica

Stage 19 convierte OrderFlow Enterprise en un proyecto **presentable en GitHub, demostrable en pocos minutos y defendible en una entrevista técnica**.

No agrega un nuevo framework de infraestructura. El objetivo es ordenar y comunicar correctamente las capacidades acumuladas hasta Stage 18.

## Entregables

- README principal orientado a GitHub.
- Arquitectura global con Mermaid.
- One-pager para recruiter/hiring manager.
- Guion de demo de 8 minutos.
- Guía de defensa técnica para entrevista.
- Documento de decisiones y trade-offs.
- Checklist de screenshots reales.
- Checklist de publicación segura.
- Presentación HTML offline.
- Scripts `START_DEMO.bat`, `OPEN_PORTFOLIO.bat` y `PREPARE_GITHUB.bat`.
- Tests Stage 19 para asegurar que la capa de portfolio no se degrade.

## Filosofía

Un recruiter no debería necesitar leer 18 documentos para entender el proyecto. El README principal debe responder rápidamente:

1. ¿Qué problema resuelve?
2. ¿Qué arquitectura utiliza?
3. ¿Qué decisiones interesantes hay?
4. ¿Cómo se ejecuta?
5. ¿Cómo sé que está probado?
6. ¿Qué partes están realmente validadas y cuáles requieren infraestructura externa?

## Qué NO hace Stage 19

- No inventa screenshots de sistemas que no estén ejecutándose.
- No afirma despliegues AWS que no se hayan ejecutado con una cuenta real.
- No convierte credenciales demo en credenciales de producción.
- No agrega una licencia OSS sin decisión explícita del propietario.
